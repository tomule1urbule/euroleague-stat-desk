# Silkiu Magnatai Fantasy Analytics App

Silkiu Magnatai Fantasy Analytics App: live EuroLeague stats with custom Fantasy Points. Results, live games with box scores, upcoming fixtures, season leaders, every player's game log, history against any opponent over past seasons, and standings.

**Open it:** https://tomule1urbule.github.io/euroleague-stat-desk/

All data comes live from the official EuroLeague API (`api-live.euroleague.net`, `live.euroleague.net`). Fantasy Points use the Silkiu Magnatai scoring rules (tap the ⓘ button in the app). PIR is the EuroLeague Performance Index Rating.

`server.js` is optional: `node server.js` serves the app at http://localhost:8787 and relays API calls, for use when a browser refuses direct calls.
