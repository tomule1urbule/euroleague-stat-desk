# EuroLeague Stat Desk

Live EuroLeague fantasy stats on one page: results, live games with box scores, upcoming fixtures, season leaders, every player's game log with PIR, and standings.

**Open it:** https://tomule1urbule.github.io/euroleague-stat-desk/

All data comes live from the official EuroLeague API (`api-live.euroleague.net`, `live.euroleague.net`). PIR (Performance Index Rating) is the EuroLeague fantasy score.

`server.js` is optional: `node server.js` serves the app at http://localhost:8787 and relays API calls, for use when a browser refuses direct calls.
